# GarageWerk
GarageWerk is an application that allows individuals and businesses to easily manage vehicle maintenance.

The goal of this project is to create an elegant solution for a problem caring car owners like myself and many others face, which is...

_How do I stay on top of all of my cars' needs?_

Split into Phases, GarageWerk will start from a simple CLI utility and build it's way up in complexity to support users globally with a visually appealing and feature-rich web application.
